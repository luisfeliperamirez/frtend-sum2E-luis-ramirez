Archivos principales que utilizarás: turnos.html + turnos.css con las tecnologias HTML5 con inputs semanticos, CSS3

Desarrolla el formulario de solicitud de turno en el archivo turnos.html. El formulario debe estar organizado 
en secciones claramente diferenciadas y utilizar los elementos semanticos de HTML5 correctamente.

Estructura del formulario
Organiza el formulario en cuatro secciones usando <fieldset> y <legend>:

Seccion 1: Datos del Paciente
Campos requeridos:
a) Nombre (type="text")
b) Apellido (type="text")
c) DNI (type="text")
d) Correo electronico (type="email")
e) Telefono (type="tel")
f) Fecha de nacimiento (type="date")
g) Genero (select): Masculino / Femenino / Otro / Prefiero no especificar

Seccion 2: Datos del Turno
Campos requeridos:
h) Especialidad (select): Clinica General, Cardiologia, Pediatria, Ginecologia, Traumatologia, 
Neurologia.
i) Medico (select): Las opciones deben cambiar segun la especialidad seleccionada. Incluye al menos 
2 medicos por especialidad. Este campo se habilita solo cuando hay una especialidad seleccionada.
j) Tipo de consulta (select): Primera consulta / Control / Resultado de estudios.
k) Fecha del turno (type="date").
l) Hora del turno (type="time").
m) Modalidad (select): Presencial / Videoconsulta.
n) Plataforma preferida (select): Zoom / Google Meet / Teams. VISIBLE SOLO si la modalidad es "Videoconsulta".

Seccion 3: Cobertura Medica
Campos requeridos:
o) Cobertura (select): OSDE / Swiss Medical / Galeno / IOMA / Medicus / Sancor Salud / Particular.
p) Numero de credencial (type="text"): VISIBLE SOLO si la cobertura NO es "Particular".
q) Plan (type="text"): VISIBLE SOLO si la cobertura NO es "Particular".

Seccion 4: Informacion Adicional
Campos requeridos:
r) Primera visita (type="checkbox"): "Es la primera vez que consulta en SaludPlus". Al marcar esta 
opcion, se muestra el campo "Como nos conocio".
s) Como nos conocio (select): Busqueda en internet / Recomendacion de un conocido / Redes 
sociales / Otro. VISIBLE SOLO si el checkbox anterior esta marcado.
t) Motivo de consulta (textarea, rows="4"): Descripcion del motivo de la consulta.
u) Estudios previos (type="checkbox"): "Tiene estudios previos relacionados con la consulta". Al 
marcar esta opcion, se muestra el campo "Descripcion de estudios".
v) Descripcion de estudios (textarea, rows="3"): VISIBLE SOLO si el checkbox anterior esta marcado.

Boton de envio
• Boton type="submit" con texto "Solicitar Turno".
• Boton type="reset" con texto "Limpiar formulario".

Requisitos de estructura HTML
• Cada campo debe tener su etiqueta <label> con el atributo for correspondiente.
• Los grupos de campos deben estar dentro de <fieldset> con su respectivo <legend>.
• Usar los tipos de input correctos (email, tel, date, time, text, checkbox).
• Agregar atributo placeholder descriptivo donde corresponda.
• Los campos de la Seccion 2 que dependen de la especialidad deben usar el atributo disabled y 
cambiar a enabled con JavaScript.

Requisitos de estilos (css)
• Formulario centrado en pantalla, con ancho maximo de 800px.
• Cada seccion (fieldset) debe tener estilos visuales diferenciados (borde, fondo suave).
• Los campos ocultos deben tener display: none; por defecto en CSS.
• Aplicar estilos de hover y focus en los campos del formulario.

Archivos principales que utilizarás: validaciones.js con las tecnologias JavaScript vanilla (ES6+), DOM manipulation

Implementa todas las validaciones del formulario en el archivo js/validaciones.js. Las validaciones deben 
ejecutarse al hacer submit del formulario e indicar visualmente el estado de cada campo mediante clases 
CSS.

Clases CSS para feedback visual
Define en turnos.css las siguientes clases y aplicalas desde JavaScript:
• campo-error: borde rojo, fondo rojo muy claro. Indica que el campo tiene un error.
• campo-ok: borde verde, fondo verde muy claro. Indica que el campo es valido.
• mensaje-error: texto de error pequeno de color rojo, visible debajo del campo.
Reglas de validacion por campo

Seccion 1 - Datos del paciente
• Nombre y Apellido: obligatorio, solo letras y espacios (incluye tildes y ene). Expresion regular 
sugerida: /^[a-zA-ZaeiouAEIOUuUnnNN\s]+$/
• DNI: obligatorio, entre 7 y 8 digitos numericos.
• Email: obligatorio, formato valido (usar expresion regular).
• Telefono: obligatorio, formato valido (puede contener +, guiones y espacios, minimo 8 digitos).
• Fecha de nacimiento: obligatoria, no puede ser una fecha futura, la edad debe estar entre 0 y 120 
anos.

Seccion 2 - Datos del turno
• Especialidad: obligatoria (no puede quedar en la opcion vacia inicial).
• Medico: obligatorio una vez que la especialidad esta seleccionada. Las opciones del select deben 
actualizarse dinamicamente al cambiar la especialidad, usando un objeto JavaScript con los 
medicos de cada especialidad.
• Tipo de consulta: obligatorio.
• Fecha del turno: obligatoria, no puede ser una fecha pasada, debe tener al menos 24 horas de 
anticipacion desde el momento actual, y debe corresponder a un dia de semana (lunes a viernes; 
rechazar sabados y domingos).
• Hora del turno: obligatoria, debe estar dentro del horario de atencion (08:00 a 20:00).
• Modalidad: obligatoria.
• Plataforma preferida: obligatoria si la modalidad es "Videoconsulta".

Seccion 3 - Cobertura medica
• Cobertura: obligatoria.
• Numero de credencial: obligatorio si la cobertura NO es "Particular". Debe tener al menos 5 
caracteres alfanumericos.
• Plan: obligatorio si la cobertura NO es "Particular".

Seccion 4 - Informacion adicional
• Como nos conocio: obligatorio si el checkbox de primera visita esta marcado.
• Motivo de consulta: obligatorio, minimo 20 caracteres.
• Descripcion de estudios: obligatoria si el checkbox de estudios previos esta marcado; minimo 20 
caracteres.

Comportamiento del formulario
Campos condicionales
Los siguientes campos deben mostrarse y ocultarse dinamicamente mediante JavaScript (modificando 
display: none / display: block):
• Medico: se habilita y actualiza sus opciones cuando el usuario selecciona una especialidad.
• Plataforma preferida: se muestra solo cuando la modalidad seleccionada es "Videoconsulta".
• Numero de credencial y Plan: se muestran cuando la cobertura es distinta de "Particular".
• Como nos conocio: se muestra cuando el checkbox de primera visita esta marcado.
• Descripcion de estudios: se muestra cuando el checkbox de estudios previos esta marcado.

Manejo del submit
• Usar preventDefault() para evitar el envio del formulario por defecto.
• Recorrer todos los campos y aplicar campo-error o campo-ok segun corresponda.
• Si existe al menos un error, usar element.scrollIntoView({ behavior: "smooth" }) para desplazarse al 
primer campo invalido.
• Si todos los campos son validos, mostrar un mensaje de confirmacion en pantalla con un numero de 
turno generado con Math.random() (formato: TURN-XXXXX, donde X son digitos).
• El mensaje de confirmacion debe incluir: nombre del paciente, especialidad, fecha y hora del turno, 
y el numero de turno generado.
