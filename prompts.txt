Archivos principales que utilizarás: index.html + styles.css con las tecnologias HTML5 semantico, CSS3 (Grid y Flexbox)

Desarrolla la pagina principal (index.html) del sitio SaludPlus. Esta pagina debe presentar la clinica de 
forma profesional, con informacion sobre sus especialidades medicas, el equipo de profesionales y las 
obras sociales aceptadas.

Con las siguientes secciones requeridas:

1. Encabezado (Header)
• Logo o nombre de la clinica: "SaludPlus".
• Menu de navegacion con enlaces a las secciones de la pagina (navegacion interna con anclas): 
Inicio, Especialidades, Medicos, Obras Sociales, Contacto.
• El menu debe permanecer visible al hacer scroll (position: sticky o fixed).

2. Seccion Hero
• Imagen de fondo o fondo de color con degradado (CSS), en la carpeta images utiliza la imagen que hay dentro como fondo .
• Titulo principal y subtitulo descriptivo.
• Boton de llamada a la accion: "Solicitar turno" que redirija a turnos.html.
• Indicadores de confianza: al menos 3 datos destacados (ej. cantidad de especialidades, años de 
experiencia, pacientes atendidos).

3. Especialidades Medicas
• Grilla con al menos 6 especialidades disponibles (ej. Clinica General, Cardiologia, Pediatria, 
Ginecologia, Traumatologia, Neurologia) cada una de las imagenes en la carpeta especialidades con su respectivo nombre.
• Cada especialidad debe mostrar un icono o imagen representativa, nombre y breve descripcion.
• Layout implementado con CSS Grid (minimo 3 columnas en pantallas grandes).

4. Nuestros Medicos
• Seccion con al menos 3 profesionales del equipo medico.
• Cada tarjeta debe incluir: nombre completo, especialidad, breve descripcion o frase.
• Placeholder de imagen (puede ser un div con fondo de color o imagen generica).
• Layout con Flexbox.

5. Obras Sociales
• Lista o grilla con al menos 6 obras sociales y/o prepagas aceptadas (ej. OSDE, Swiss Medical, 
Galeno, IOMA, Medicus, Sancor Salud).
• Presentacion clara con nombre de cada cobertura.

6. Contacto y Footer
• Datos de contacto: direccion, telefono, email, horario de atencion.
• Mapa placeholder (un div con texto o imagen representativa).
• Footer con derechos reservados y nombre del autor.
Requisitos CSS
• Usar CSS Grid para la seccion de Especialidades.
• Usar Flexbox para el header y la seccion de Medicos.
• Paleta de colores coherente y profesional, acorde a un sitio medico.
• Fuentes legibles; se puede usar Google Fonts (max. 2 familias).
• El sitio debe verse correctamente en pantallas de al menos 1024px de ancho.

1 prompt: 
Archivos principales que utilizarás: turnos.html + turnos.css con las tecnologias HTML5 con inputs semanticos, CSS3

Desarrolla el formulario de solicitud de turno en el archivo turnos.html. El formulario debe estar organizado 
en secciones claramente diferenciadas y utilizar los elementos semanticos de HTML5 correctamente.

Estructura del formulario
Organiza el formulario en cuatro secciones usando <fieldset> y <legend>:

Seccion 1: Datos del Paciente
Campos requeridos:
a) Nombre (type="text")
b) Apellido (type="text")
c) DNI (type="text")
d) Correo electronico (type="email")
e) Telefono (type="tel")
f) Fecha de nacimiento (type="date")
g) Genero (select): Masculino / Femenino / Otro / Prefiero no especificar

Seccion 2: Datos del Turno
Campos requeridos:
h) Especialidad (select): Clinica General, Cardiologia, Pediatria, Ginecologia, Traumatologia, 
Neurologia.
i) Medico (select): Las opciones deben cambiar segun la especialidad seleccionada. Incluye al menos 
2 medicos por especialidad. Este campo se habilita solo cuando hay una especialidad seleccionada.
j) Tipo de consulta (select): Primera consulta / Control / Resultado de estudios.
k) Fecha del turno (type="date").
l) Hora del turno (type="time").
m) Modalidad (select): Presencial / Videoconsulta.
n) Plataforma preferida (select): Zoom / Google Meet / Teams. VISIBLE SOLO si la modalidad es "Videoconsulta".

Seccion 3: Cobertura Medica
Campos requeridos:
o) Cobertura (select): OSDE / Swiss Medical / Galeno / IOMA / Medicus / Sancor Salud / Particular.
p) Numero de credencial (type="text"): VISIBLE SOLO si la cobertura NO es "Particular".
q) Plan (type="text"): VISIBLE SOLO si la cobertura NO es "Particular".

Seccion 4: Informacion Adicional
Campos requeridos:
r) Primera visita (type="checkbox"): "Es la primera vez que consulta en SaludPlus". Al marcar esta 
opcion, se muestra el campo "Como nos conocio".
s) Como nos conocio (select): Busqueda en internet / Recomendacion de un conocido / Redes 
sociales / Otro. VISIBLE SOLO si el checkbox anterior esta marcado.
t) Motivo de consulta (textarea, rows="4"): Descripcion del motivo de la consulta.
u) Estudios previos (type="checkbox"): "Tiene estudios previos relacionados con la consulta". Al 
marcar esta opcion, se muestra el campo "Descripcion de estudios".
v) Descripcion de estudios (textarea, rows="3"): VISIBLE SOLO si el checkbox anterior esta marcado.

Boton de envio
• Boton type="submit" con texto "Solicitar Turno".
• Boton type="reset" con texto "Limpiar formulario".

Requisitos de estructura HTML
• Cada campo debe tener su etiqueta <label> con el atributo for correspondiente.
• Los grupos de campos deben estar dentro de <fieldset> con su respectivo <legend>.
• Usar los tipos de input correctos (email, tel, date, time, text, checkbox).
• Agregar atributo placeholder descriptivo donde corresponda.
• Los campos de la Seccion 2 que dependen de la especialidad deben usar el atributo disabled y 
cambiar a enabled con JavaScript.

Requisitos de estilos (css)
• Formulario centrado en pantalla, con ancho maximo de 800px.
• Cada seccion (fieldset) debe tener estilos visuales diferenciados (borde, fondo suave).
• Los campos ocultos deben tener display: none; por defecto en CSS.
• Aplicar estilos de hover y focus en los campos del formulario.
